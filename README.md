# RealWeather — суперячейки, торнадо, объёмные облака, небо и радар (NeoForge 1.21.1)

> **Статус: исходники написаны, но НЕ собирались и НЕ запускались автором.**
> Подтверждено только то, что Java-код проходит синтаксический разбор (javac без библиотек Minecraft).
> Компиляция против NeoForge, загрузка шейдеров и картинка в игре **не проверены** — при первой сборке
> возможны ошибки в сигнатурах API и в GLSL. Присылайте вывод `gradlew build` / `latest.log` — исправим.

Это **упрощённая игровая симуляция**, а не расчёт CM1. Адаптер CM1 в этой версии **не реализован**.

## Требования
- Java 21, Minecraft 1.21.1, NeoForge 21.1.x (версия в `gradle.properties` → `neo_version`, поставьте свою).
- Gradle wrapper в архив не входит. Варианты: открыть проект в IntelliJ IDEA (сам подтянет Gradle), либо
  скопировать `gradlew`, `gradlew.bat`, папку `gradle/` из официального MDK для 1.21.1 (ModDevGradle).
  Если плагин `net.neoforged.moddev` версии 2.0.78 не находится — возьмите версию из актуального MDK.

## Сборка (PowerShell)
```powershell

```

Запуск клиента из среды: `.\gradlew.bat runClient` (проверьте `.\gradlew.bat tasks`).

## Проверка в игре
1. Создайте мир (читы вкл.), Оверворлд. Облака ванильные отключаются автоматически (`disableVanillaClouds`).
2. `/realweather tornado` — торнадическая суперячейка в 320 блоках впереди, идёт на вас.
   `/realweather storm [0.1-1]` — растущий шторм. `/realweather intensity <v>`, `/realweather clear`, `/realweather info`.
3. Смотрите: башня, наклонённая по ветру, широкая наковальня, wall cloud, воронка, пылевая юбка, дождевая завеса.
4. Подойдите к торнадо: сначала ветер и притяжение, затем вращение и подъём. Игрока двигает клиент (в Minecraft
   движение игрока клиент-авторитарно), мобов и предметы — сервер. На dedicated-сервере включите `allow-flight=true`,
   иначе античит кикнет за «полёт».
5. Клавиша **K** — радар (отражаемость / радиальная скорость, масштаб колесом мыши, история кадров назад).
6. Небо: смотрите закат/рассвет/ночь (`/time set 12500`, `/time set 23000`, `/time set 18000`).

## Что реализовано
- `storm`: единая ячейка (центр, направление, жизненный цикл рост→зрелость→распад, неустойчивость из температуры биома
  и времени суток), молнии (внутри облака и в землю), синхронизация редкими пакетами.
- `tornado`: поле скорости (тангенциальная/радиальная/вертикальная компоненты, профиль Ранкина, высотные профили,
  турбулентность, защита от NaN/нуля) — одни и те же формулы для физики, частиц и радара.
- Рендер: полноэкранный ray marching в GLSL (ограниченное число шагов, ранний выход, глубина сцены, шум в
  координатах шторма, 4 профиля качества), процедурное небо (градиент, закат, солнце, луна, звёзды, 2D-облака).
- Локальный дождь/гроза через ванильные уровни, град (частицы), частицы обломков, вспышки и гром с задержкой.
- Радар с палитрой dBZ, меткой торнадо, стрелкой движения, историей.
- Конфиги: `realweather-server.toml`, `realweather-client.toml` (все значения ограничены диапазонами).

## Известные ограничения (честно)
- Не проверено компилятором и в игре. Первый запуск шейдеров — самое рискованное место
  (массив `SD[64]` как float-uniform, чтение буфера глубины, порядок стадий `RenderLevelStageEvent`).
- Штормы не сохраняются между перезагрузками мира.
- Разрушения блоков нет (намеренно). Нет звука самого торнадо.
- Марширование идёт в полном разрешении (без буфера половинного разрешения); на GTX 1650 начните с MEDIUM.
- Совместимость с Sodium/Iris и шейдерпаками не проверялась (проход рисуется на стадиях Forge-событий).
- Ванильное небо заменяется целиком в Оверворлде; фазы луны не учитываются.
- Влажность не моделируется (только температура биома и время суток).
- CM1: не реализован. Реальный CM1 требует его файлов результатов; выдумывать формат я не стал.

## Сборка через GitHub (без локальных проблем)
1. Положите файлы официального MDK 1.21.1, если хотите свой wrapper: `gradlew`, `gradlew.bat`, `gradle/wrapper/gradle-wrapper.jar`
   (папка `gradle/wrapper/gradle-wrapper.properties` уже есть). Для CI они не обязательны.
2. `git init && git add . && git commit -m "RealWeather" && git push` в свой репозиторий на GitHub.
3. Вкладка Actions → Build RealWeather → после зелёной галочки скачайте артефакт `realweather-jar`.
